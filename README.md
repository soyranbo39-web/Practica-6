# Practica-6

Aplicacion Android en Kotlin para demostrar los widgets DatePicker y TimePicker, de acuerdo con la Tarea 6.

## Requisitos cubiertos

- Un Activity con una pareja TextView + Button para DatePicker.
- Un Activity con una pareja TextView + Button para TimePicker.
- Ambos pickers se muestran mediante dialogos.
- Los TextView se actualizan con la fecha y hora seleccionadas.
- Los dialogos son DialogFragment para que se mantengan al rotar el dispositivo.

## Estructura principal

- app/src/main/java/com/example/practica6/MainActivity.kt
- app/src/main/java/com/example/practica6/DatePickerDialogFragment.kt
- app/src/main/java/com/example/practica6/TimePickerDialogFragment.kt
- app/src/main/java/com/example/practica6/MainViewModel.kt
- app/src/main/res/layout/activity_main.xml

## Abrir en Android Studio

1. Abrir la carpeta del proyecto.
2. Esperar la sincronizacion de Gradle.
3. Ejecutar la app en emulador o dispositivo.

## Entrega

Para la entrega de la tarea, comprimir el directorio completo del proyecto y anexar el PDF con capturas de pantalla del funcionamiento.
